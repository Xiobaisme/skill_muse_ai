# skill_muse_ai

Kumpulan custom skill untuk [Muse](https://muse.ai/join), agen AI pribadi.

## Cara daftar Muse

1. Buka link pendaftaran: **https://muse.ai/join**
2. Buat akun lalu selesaikan pendaftaran.
3. Setelah masuk, buka **Settings**.
4. Masukkan kode referral: **`QR8LGH`**
5. Lakukan ini **dalam 48 jam setelah bergabung**. Kode yang dimasukkan setelah lewat 48 jam tidak berlaku.

Bonus: kamu dan pemilik kode sama-sama mendapat **1 miliar token Muse**.

> Disclosure: link dan kode di atas adalah referral milik pemilik repo.

### Kalau Muse tidak tersedia di wilayahmu

Kalau halaman pendaftaran tidak bisa dibuka atau layanan belum tersedia di negaramu, coba pakai **VPN** dengan server di negara yang didukung, lalu ulangi langkah di atas. Periksa dulu syarat layanan Muse, karena aturan soal wilayah bisa berbeda dan itu tanggung jawabmu sendiri.

## Keamanan

- Jangan pernah commit file `.env`, private key, seed phrase, atau API key ke repo ini.
- Baca isi `SKILL.md` dan semua file di `scripts/` sebelum memakai skill apa pun.
- Jalankan skill yang berhubungan dengan transaksi hanya di agen yang tidak punya akses ke wallet berisi dana asli.
